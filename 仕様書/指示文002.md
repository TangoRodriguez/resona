# 具体的に追加したい表現

## Glass

4. RMSまたは平均振幅から `level: 0..1` を算出
5. levelをReact stateに渡す
6. LevelMeterに反映
7. SoundMatterCanvasにlevelを渡して、以下を変化させる

   * glow intensity
   * orb scale
   * ripple amplitude
   * internal curve movement
   * Bloom petal opening
8. 無音時はlevelを急に0にせず、smooth dampingする

推奨ファイル：

* `src/lib/audio/micInput.ts`
* `src/hooks/useMicLevel.ts`
* 必要なら `src/lib/audio/audioTypes.ts`

仕様：

```ts
type MicState = {
  permission: "idle" | "requesting" | "granted" | "denied";
  level: number; // 0..1
  isListening: boolean;
  error?: string;
};
```

* マイク未許可時は小さく自然な案内を出す
* 大きなモーダルは不要
* 許可後は `Touch / Hum` の近くに小さく listening 状態を出す
* 音量が入るとLevel meterと中央オブジェクトが滑らかに反応する

重要：

* 音量値はそのまま使わず、必ずsmoothingする
* 反応は激しすぎず、RESONAらしく上品にする
* 既存のUIを壊さない
* npm run build が通る

# さらに具体的な実装方針

## Canvas側で持つべきパラメータ

`SoundMatterCanvas` に渡すpropsはこうすると後から拡張しやすい。

```ts
type SoundMatterCanvasProps = {
  mode: "solo" | "capture" | "merge";
  matter: "glass" | "liquid" | "bloom";
  level: number;
  resonance: number;
  pitch?: number | null;
  pitchConfidence?: number;
  isRecording?: boolean;
  elapsedSeconds?: number;
};
```

描画側では、直接DOM状態を見ずに、このpropsだけで描く。

---

## Visual Matter内部パラメータ

あとで音声入力に繋げるために、内部でこういう値に変換する。

```ts
const energy = smooth(level);
const breath = 0.5 + Math.sin(time * 0.8) * 0.5;
const pulse = isRecording ? 1.0 : 0.35;
const pitchNorm = pitch ? normalizePitch(pitch) : 0.5;
```

そして、

* `energy` → 明るさ、波の大きさ
* `breath` → ゆっくりした呼吸
* `pulse` → 録音リング
* `pitchNorm` → 色、位置、線の高さ

に使う。
